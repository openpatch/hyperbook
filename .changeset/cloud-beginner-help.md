Help for teachers new to Markdown and Typst in the editor. A formatting toolbar above pages and Typst files writes headings, bold, italic, lists, links, images, tables and code in the file's own syntax; each button's tooltip shows what it writes. On pages, *Element* opens a searchable list of elements by what they do ("Quiz", "Hint or solution", "Python", "Drawing"), grouped and described in English and German, and typing `/` at the start of a line offers the same list (and the formats, also in Typst files). An element kept in a file of its own (drawing, learning map, task flow, memory diagram, Scratch project) is made next to the page, linked with `./…` and opened in its editor; a structogram opens in its visual editor right away. Images pasted, dropped or picked with the toolbar are uploaded next to the page or Typst file, also on glossary pages, and linked relatively (`![photo](./photo.png)`, `#image("photo.png")`). Every error and warning in the editor offers *Explain with AI*, which asks the assistant in a new chat with the message and the lines around it. The preview serves files kept next to glossary pages under `/glossary/…`.
