The editors know the new `dock` attribute. In the Cloud editor, completion and hover help offer `dock` on `pyide`, `webide`, `p5`, `openscad`, `typst`, `onlineide`, `sqlide`, `excalidraw`, `textinput`, `struktolab`, `blockflow-editor` and `jmp`, and the AI assistant knows it too: a `dock` topic in its documentation and a line in each of these elements' docs tell it when to use it. The VS Code extension has a docked variant of each of their snippets: `:pyide-dock`, `:webide-dock`, `:p5-dock`, `:openscad-dock`, `:typst-dock`, `:onlineide-dock`, `:sqlide-dock`, `:excalidraw-dock`, `:textinput-dock`, `:struktolab-dock`, `:blockflow-editor-dock` and `:jmp-dock`.
