Editor: a History pane shows the book's commits — every save, upload and push is one — with its author, date, message and line counts (+/−, binary files aside). The list is paged from the server (a book can have many commits) and can be narrowed to the changes of the open file. Clicking a commit shows its diff in a dialog; commits never change, so each diff is fetched once and carries its sha as the ETag. The pane joins the editor next to the AI assistant and the preview, resizable like they are, in English and German.
