The class view works for big books. It shows one column per page with how many of its tasks each student worked on, and a page opens into its tasks. By default it shows only the pages someone in the group worked on, and a section picker narrows it to a chapter; both choices are remembered per group, and the CSV follows them. The element index names each page's sections and uses the page title the navigation shows.
