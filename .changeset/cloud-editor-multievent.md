`:::multievent` blocks in the editor now get real syntax highlighting instead of one flat background: the event command (`r1`, `R`, `z`, `X`, …) is colored like a directive name, braces and the `|`/`~~` separators as punctuation, a leading `!` as the correct-term marker, and the terms as values — in the light and dark themes alike, with nested braces (e.g. in `$\sqrt{2}$`) handled. In English and German.
