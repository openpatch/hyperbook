Struktolab structograms can be written in Java, Python or JavaScript. Give the code block its language (` ```java `, ` ```python `, ` ```js `) or set `code="java"` on the directive; the structogram is built from the code, and in edit mode students write their algorithm in the code box under the diagram. `code="none"` hides that box. Students' code is now saved with their structogram, so it comes back as they wrote it. Updates struktolab to 0.8.0, which also makes dragging blocks calmer: the diagram stays still and one line shows where a block lands. In the cloud editor, "Edit visually" is offered for pseudocode blocks only.
