The editor gets a quick-open popup (Ctrl/Cmd+P) to search the book's files, a file tree that filters, unfolds the open file and moves files by dragging them into folders, a settings menu with font size, line numbers and spell check, and a per-book spell-check dictionary: Hunspell via Typo.js, aware of pages' code, frontmatter and directive syntax, with right-click suggestions and words to add or remove. A right-click opens the editor's own context menu — cut, copy, paste, select all, undo and redo — instead of the browser's; on a misspelled word it shows the corrections and "Add to dictionary".
