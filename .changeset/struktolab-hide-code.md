Updates struktolab to 0.9.0. `struktolab` takes `hideCode`: in edit mode the diagram alone, without the code under it, while `code` (or the fence's language) keeps saying which language it is written in, so Java's function headers stay Java's and the editor's *Show code* brings the code back in that language. `code="none"` still hides the code. The structogram editor draws its own colours, so it is readable on a dark page, and its View menu opens into the editor instead of being cut off. The Cloud editor completes `hideCode`.
