Managing a class is safer and quicker. Deleting a student now asks first, since it deletes everything the student saved. Students can be selected to print only their cards, give them new QR codes, move them to another group of the book (their work stays) or delete them. A student's menu has "Print card" for a lost card, and a new QR code offers to print it right away. The print page warns when passwords and QR codes cannot be shown because the server's credentials key changed. Copy buttons now say when copying failed, and copying works on instances served over plain http. Preview opens in the same tab when pop-ups are blocked. Pages show "Loading…" while they load, and "not found" or an error with "Try again" instead of an empty page.
