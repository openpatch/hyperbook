# Checkliste

Eine Checkliste ist eine ungeordnete Liste, deren Einträge mit `[ ]` oder `[x]`
beginnen. Verwende ein Leerzeichen für eine offene und ein `x` für eine
erledigte Aufgabe.

```md
- [ ] Kapitel lesen
- [x] Beispiel ausprobieren
- [ ] Aufgabe bearbeiten
```

- [ ] Kapitel lesen
- [x] Beispiel ausprobieren
- [ ] Aufgabe bearbeiten

In einem gebauten Hyperbook kannst du die Kontrollkästchen aktivieren und
deaktivieren. Hyperbook speichert ihren Zustand im Browser und stellt ihn beim
nächsten Besuch der Seite wieder her. Der gespeicherte Zustand wird auch beim
Export, Import und bei der Synchronisierung mit Hyperbook Cloud berücksichtigt.
