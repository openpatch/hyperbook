The editor's AI assistant works like a full chat now. Conversations are kept per teacher and book: they survive a reload, are listed in the pane's history, can be renamed and deleted, and a follow-up sees the whole conversation, not just the last few answers cut to 4000 characters. A reasoning model's thinking streams live into a "Thinking…" block that folds away once the answer starts, and a tool call shows its progress while it is being written ("Writes arbeitsblatt-2.typ — 6.2 KB"), so a long answer no longer looks stuck. An answer cut off by the output cap goes on by itself: cut-off text is continued, a cut-off file write is retried in smaller pieces, and thinking that used up the cap is told to act — thinking is never passed off as the answer any more. When the step limit ends unfinished work, *Continue* picks it up. File changes the teacher has not accepted or denied yet carry over, so "make task 5 harder" changes the pending draft. Messages can be edited and resent, answers regenerated or retried, and images, PDFs and text files attached (button, paste or drop); a picker sets how hard a reasoning model thinks. The provider timeout is an idle timeout now — it fires only when the provider goes silent, never while it streams — and the defaults grow to 65536 output tokens (only what is written is billed; a provider that rejects that is asked again with 16k) and 12 steps. Needs a database migration (applied on start).
