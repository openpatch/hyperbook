# p5 (p5.js sketches)

`:::p5` shows or edits a p5.js sketch. The sketch is a `js` fenced block inside the
directive; further `.js` files go in `::file{path="helpers.js" src="…"}` entries,
loaded before the sketch in the order written.

    :::p5{height=400 mode="editor"}

    ```js
    function setup() { createCanvas(400, 400); }
    function draw() { background(220); ellipse(200, 200, 100, 100); }
    ```

    :::

Attributes: `height` (default `calc(100dvh - 80px)`), `mode` (`preview` default,
`editor`), `id`, `files` (what readers may do with files), `accept` (default `.js`),
`compare`, `pass` (percent that counts as solved, default 98). A `.js` file can also
be loaded with `src` instead of inline code.

## Compare with a solution (CSSBattle-style)

Add `compare` (and `mode="editor"`) plus a solution sketch with `role="solution"`:
every **Update** scores how much of the reader's sketch matches.

    :::p5{mode="editor" compare pass=95}

    ```js
    function setup() { createCanvas(200, 200); }
    ```

    ```js file="solution.js" role="solution"
    function setup() {
      createCanvas(200, 200);
      background(240); noStroke(); /* ...the target picture... */
    }
    ```

    :::

- `random()` and `noise()` are seeded identically for reader and solution, so a
  sketch using them can match exactly.
- Scoring and views as in webide: Colour 50% / Outline 30% / Area 20%; split view
  Yours/Target with draggable line, Overlay, Differences, hold-Target; target
  colours clickable to copy hex; solved when total and each part reach `pass`
  (default 98); green outline when solved.
