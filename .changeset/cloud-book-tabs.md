The book page in Hyperbook Cloud is split into tabs instead of showing everything at once: Publishing, Versions, Groups, People and Settings. The tab is kept in the address, so a reload or a shared link opens the same one, and the way back from a group opens the book on its groups. Versions are listed ten at a time, newest first, and can be filtered by version or note; the build history is paged too. When AI is set up, the publish dialog can suggest a note for the new version from what changed since the live one.
